**EDDY BEATS \- Official Website**

Official website for **Eddy Beats**, a music producer, beatmaker, and recording studio based in Cape Town, South Africa.

This website serves as an online portfolio and booking platform, allowing artists to explore beat licensing options, listen to sample tracks, tour studio setup, and book recording or production sessions.

 Features

* **Hero Section:** Clear call-to-action for beat purchasing and session bookings.  
* **Beat Licensing Table:** Overview of pricing tiers (MP3 Lease, WAV Lease, Trackouts, Unlimited, Exclusive) linked directly to BeatStars.  
* **Studio Showcase:** Overview of studio environment, audio gear list, and video preview.  
* **Audio Showcase:** Native HTML5 audio players for demo tracks.  
* **Functional Contact Form:** Powered by **Web3Forms** to send booking requests directly to email without requiring a dedicated backend server.  
* **Fully Responsive & Lightweight:** Clean HTML5 structure and custom CSS styling for high-speed performance on mobile and desktop.
